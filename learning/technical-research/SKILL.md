# Technical Research

- Clarify the research question and the decision the research should support.
- For current, changing, or version-specific claims, consult current authoritative sources when browsing is available.
- Prefer primary sources: official documentation, specifications, release notes, source repositories, and papers.
- Use independent sources to cross-check consequential claims.
- Separate verified facts, interpretation, estimates, and open questions.
- Compare alternatives using criteria relevant to the user's constraints: capability, compatibility, cost, complexity, maintenance, security, and lock-in.
- Include dates or version numbers when freshness matters.
- Cite claims derived from external sources using the host's supported citation mechanism.
- Do not claim to have browsed or checked documentation when no such access occurred.
- End with a practical conclusion tied to the user's stated goal.
